# TodayDDL

一款面向高校学生与个人日常的轻量级 Android 截止日期（DDL）管理应用。

## 核心功能

- **智能分组与紧迫度提示**：首页展示公历日期、学期周数与未完成数量；按「已逾期 / 今天 / 即将到来 / 已完成」自动分组排序，根据剩余时间区分配色，支持亮/暗色主题与标签筛选。
- **公历 / 学期周数双模式录入**：支持按公历日期或「第 1–30 周 + 星期」录入并实时双向换算；支持全天任务与精确到分钟的时间设置。
- **定时弹窗提醒**：内置多种提前提醒策略并支持自定义提醒日期与时间，实时预览触发时间与倒计时，准点触发且重启后自动恢复。
- **状态栏常驻通知**：在通知栏常驻展示今日待办列表，支持无任务时自动隐藏，内置权限状态自检与测试提醒。
- **分类标签管理**：预置作业、实验报告、考试、项目等标签，支持自定义新增、重命名、配色与删除。

## 后续计划

- **四象限视图**：按时间紧迫度与重要程度对任务进行四象限分类展示。
- **文本一键导入**：自动解析包含 DDL 信息的文本并一键批量导入。
